# Terminology Glossary

| Term | Description |
|------|-------------|
| **Radio Access Network (RAN)** | Used for wireless communication between User Equipment and the core network. |
| **Access Point (AP)** | Allows UEs to bind to the network, enforce network policies through the HSS, and serves as a gateway for data transmission. |
| **User Equipment (UE)** | Gives users access to network services. |
| **Network Function (NF)** | A logical function that provides specific services within the core network. |
| **Service-Based Interface (SBI)** | A communication interface that allows NFs to interact with each other using HTTP and JSON. |

## List of Network Functions

| Network Function | Purpose |
|------------------|---------|
| **Home Subscriber Server (HSS)** | Manages subscriber information and authentication. Maintains registry of Network Functions. |
| **Short Message Service Function (SMSF)** | Handles the sending and receiving of short messages between UEs. |

## List of Protocols

| Protocol | Purpose |
|----------|---------|
| **Network Element Protocol (NEP)** | Defines structured communication between two parties using a common packet envelope composed of a header and a list of network elements. |
